# EATING-GO_P3L_A_RUTIN
Eating Go adalah platform berbasis web untuk pencarian lokasi kafe dan reservasi tempat duduk (booking seat) secara real-time.  Fitur Utama:  Pencarian daftar kafe  Reservasi tempat duduk real-time untuk pengguna terdaftar  Autentikasi login pengguna (Pelanggan) dan Admin/Karyawan kafe
